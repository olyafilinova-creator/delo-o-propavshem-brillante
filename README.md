# Дело о пропавшем бриллианте — эпизод 1

Автономный HTML-прототип первой сцены детективной игры. Внешние библиотеки и сетевые запросы не используются.

Перед сценой музея есть короткое интерактивное вступление: ребёнок знакомится с делом, осматривает голубую ленту и запускает расследование.

Каждая локация начинается с короткой сюжетной главы: она объясняет, куда привёл след и зачем нужно выполнить задание.

Кнопка `♪` в правом верхнем углу включает и выключает спокойную фоновую мелодию. Она создаётся самой игрой, поэтому отдельный музыкальный файл и интернет не нужны.

После музея открывается комната видеонаблюдения. В ней ребёнок решает четыре задания на время и располагает записи камер от самой короткой к самой длинной.

Третья локация — кабинет допросов: ребёнок проверяет три показания с помощью сложения и вычитания, а затем открывает ящик кодом `17`.

Четвёртая локация — музейный архив: ребёнок разгадывает шесть выражений со скобками, умножением, делением, сложением и вычитанием, соблюдая порядок действий.

Пятая локация — реставрационная мастерская: ребёнок распознаёт прямоугольные, остроугольные и тупоугольные треугольники, восстанавливая витраж.

Шестая локация — старая башня музея: ребёнок решает задачу в два действия про воздушные шарики, получает код `36` и открывает сундук со следующей уликой.

Финальная, седьмая локация — комната остановившихся часов: ребёнок решает задачу про привидения в двух замках, открывает последний механизм и возвращает Голубой бриллиант в музей.

## Как открыть

1. Распакуйте ZIP-архив, сохранив вложенные папки.
2. Откройте `index.html` двойным щелчком в современном браузере (Chrome, Edge, Firefox или Safari).
3. Ведите мышью или пальцем по тёмному залу. Найденные карточки можно нажимать и решать.

## Для GitHub Pages

Загрузите **содержимое** этой папки в корень репозитория GitHub. В настройках репозитория откройте **Settings → Pages**, выберите ветку `main` и папку `/ (root)`. После сохранения GitHub выдаст адрес игры.

## Состав

- `index.html` — сцена и интерфейс;
- `css/style.css` — адаптивное оформление и анимации;
- `css/intro.css` и `js/intro.js` — интерактивное вступление;
- `js/tasks.js` — **ваш короткий список примеров, ответов и подсказок**;
- `js/game.js` — световой луч, проверка, звуки и папка улик;
- `images/lis-detektiv.png`, `images/museum-hall.png`, `images/surveillance-room.png`, `images/interrogation-room.png`, `images/museum-archive.png`, `images/restoration-workshop.png`, `images/museum-tower.png`, `images/stopped-clocks-room.png` — Лис, герои и рисованные фоны локаций.

### Как заменить примеры

Откройте `js/tasks.js` в любом текстовом редакторе. У каждого задания можно поменять:

- `text` — сам пример, например `8 × 7 = ?`;
- `answer` — правильный ответ, например `56` (без кавычек);
- `hint` — подсказку для ребёнка.

В файле уже есть десять заготовок. Не меняйте имена `p01`–`p10` и знаки пунктуации вокруг них.
